## Fonts

| Family | Source | Weights loaded | CSS variable | SPEC ref |
|---|---|---|---|---|
| **Sora** | `next/font/google` | 400, 600, 700, 800 | `--font-sora` | §1, §2.2 |
| **Inter** | `next/font/google` | 400, 500, 600 | `--font-inter` | §1, §2.2 |

- Both are self-hosted by `next/font` at build time (zero external network requests).
- `display: "swap"` is the default; no FOUT/FOIT flash.
- Sora is used for headings only (h1–h4 + wordmark/logo). Inter is used for everything else.
- Never use Sora below 16px (SPEC §2.2).

## External media / images

**None.** The project contains zero raster images. All visuals are:
- CSS gradients (hero washes, blog placeholder images, chip tints)
- Lucide icons (SVG, tree-shaken at build time)
- `next/og` `ImageResponse` for the OG image (rendered server-side, not a file in `/public`)

The only files in `/public/` are:
- `favicon.ico` (or `.svg` — either is fine)
- The OG image is generated by `app/opengraph-image.tsx`, not stored as a static file

## Environment variables

| Name | Required | Where set | Purpose |
|---|---|---|---|
| `RESEND_API_KEY` | Optional (dev) / Required (prod email) | Vercel env | Resend API authentication |
| `RESEND_FROM_EMAIL` | Optional | Vercel env | Sender address (defaults to `onboarding@resend.dev`) |
| `CONTACT_TO_EMAIL` | Optional (dev) / Required (prod email) | Vercel env | Where contact form submissions are sent |
| `NEXT_PUBLIC_SITE_URL` | Optional | Vercel env | Base URL for OG tags and sitemap |

- All four are listed in `.env.example` (committed).
- `.env.local` is gitignored and never committed.
- If `RESEND_API_KEY` or `CONTACT_TO_EMAIL` are absent, the API still returns 200 and logs server-side — the site works locally without email.

## Version pinning notes

- Pin `framer-motion@11` to avoid surprise major bumps.
- Pin `zod@3` — Zod v4 has a different `errorMap` API; phase 7 must check the installed version.
- `lucide-react`, `react-hook-form`, `@hookform/resolvers`, `clsx`, `tailwind-merge`, and `resend` are stable and can be unpinned.
- `prettier` and `prettier-plugin-tailwindcss` can be unpinned.
